# U7 · Cyber — Trainer BTS SIO SLAM

**🔗 En ligne :** https://neroclaw.github.io/u7-cyber-trainer/ · **📦 Code :** https://github.com/NeroClaw/u7-cyber-trainer

---

Trainer de révision de l'unité **U7 (cybersécurité)** du BTS SIO, option SLAM.

## Contenu
- 16 sections, 128 cartes, 30 ateliers auto-corrigés.
- Couvre XSS, CSRF, SSRF, clickjacking, injections SQL, MFA, supply chain, durcissement d'un SI.
- Mode Focus (par défaut) : une carte à l'écran, navigation ← →.
- Version autonome en un seul fichier : `u7-cyber-trainer-standalone.html`.

## Technique
Site statique : `index.html` + `data.js` + `app.js` + `styles.css`, aucune dépendance de build.
